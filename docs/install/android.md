# Install the app on Android

[Deutsch](de/android.md) · [Back to downloads](../../README.md#download)

**File:** `Remote-for-ADI-2-Android-1.3.0.apk` from the [download section](../../README.md#download).
**Requires:** Android smartphone or tablet with USB host support (USB OTG), or a computer running [Remote for ADI-2 Host](../../README.md#download) for Wi-Fi control.

## 1. Download

Download the APK in **Chrome** itself. If the link opens inside another app (for example GitHub, Gmail or a messenger), the download stops at 100 % and the file cannot be opened: tap **⋮ → Open in Chrome** first.

## 2. Install

1. Open the downloaded APK (Chrome shows it when the download finishes, or open **Files → Downloads**).
2. When Android asks, allow installing apps from this source, go back and tap **Install**.
3. If Google Play Protect warns, choose **More details → Install anyway**.
4. If Play Protect blocks the installation, turn it off temporarily: **Play Store** → profile picture at the top right → **Play Protect** → gear icon → switch off **Scan apps with Play Protect**. Turn it back on after installing.

## 3. Connect the ADI-2

1. Connect the ADI-2 with a data-capable USB cable, usually through a USB-OTG adapter.
2. On the ADI-2, switch on **MIDI Control**:
   - DAC: **SETUP → Options → Remap Keys / Diag → MIDI Control**
   - ADI-2 Pro / ADI-2/4 Pro: **SETUP → Options → Device Mode / DSD → MIDI Control**
3. Start the app and confirm the USB permission dialog. On first launch, a wizard guides you through setup, including the player display.

For Wi-Fi control through a computer, install the host for [Mac](host-mac.md) or [Windows](host-windows.md), or [Remote for ADI-2 for Linux](linux.md).

## Updates

The app reports new versions (can be switched off). Install an update over the existing app; settings are kept.
