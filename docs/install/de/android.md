# App auf Android installieren

[English](../android.md) · [Zurück zu den Downloads](../../README.de.md#download)

**Datei:** `Remote-for-ADI-2-Android-1.3.0.apk` aus dem [Downloadbereich](../../README.de.md#download).
**Voraussetzung:** Android-Smartphone oder -Tablet mit USB-Host-Unterstützung (USB-OTG) oder ein Computer mit [Remote for ADI-2 Host](../../README.de.md#download) für die Steuerung per WLAN.

## 1. Herunterladen

Die APK direkt in **Chrome** herunterladen. Öffnet sich der Link in einer anderen App (zum Beispiel GitHub, Gmail oder einem Messenger), bleibt der Download bei 100 % hängen und die Datei lässt sich nicht öffnen: dann zuerst **⋮ → In Chrome öffnen** wählen.

## 2. Installieren

1. Die heruntergeladene APK öffnen (Chrome zeigt sie nach dem Download an, sonst **Dateien → Downloads**).
2. Wenn Android fragt, die Installation aus dieser Quelle erlauben, zurückgehen und **Installieren** tippen.
3. Warnt Google Play Protect: **Weitere Details → Trotzdem installieren**.
4. Blockiert Play Protect die Installation, vorübergehend abschalten: **Play Store** → Profilbild oben rechts → **Play Protect** → Zahnrad → **Apps mit Play Protect scannen** ausschalten. Nach der Installation wieder einschalten.

## 3. ADI-2 verbinden

1. Den ADI-2 mit einem datenfähigen USB-Kabel verbinden, meist über einen USB-OTG-Adapter.
2. Am ADI-2 **MIDI Control** einschalten:
   - DAC: **SETUP → Options → Remap Keys / Diag → MIDI Control**
   - ADI-2 Pro / ADI-2/4 Pro: **SETUP → Options → Device Mode / DSD → MIDI Control**
3. App starten und die USB-Berechtigung bestätigen. Beim ersten Start führt ein Assistent durch die Einrichtung, auch durch die Player-Anzeige.

Für die Steuerung per WLAN über einen Computer den Host für [Mac](host-mac.md) oder [Windows](host-windows.md) bzw. [Remote for ADI-2 für Linux](linux.md) installieren.

## Updates

Die App meldet neue Versionen (abschaltbar). Ein Update über die vorhandene App installieren; die Einstellungen bleiben erhalten.
